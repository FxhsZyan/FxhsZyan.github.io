
# Zyann.Dev — Personal Portfolio

Live site: [fxhszyan.github.io](https://fxhszyan.github.io)

My personal developer portfolio — built to showcase who I am, what I've built, and how to reach me. Designed with a dark, spider-verse-inspired aesthetic, an interactive cursor web effect, and a light/dark theme toggle.

## About Me

I'm **Zyann C. Bugtong**, a BSIT student at the University of San Carlos and an aspiring Full-Stack Developer with a strong interest in both game development and web development. I enjoy building practical, clean, and reliable software — and I'm always picking up new tools and technologies along the way.

I hold certifications in **CCNA**, **Docker**, and **Kubernetes**.

## Features

- Animated hero section with a typewriter effect and interactive particle/web cursor trail
- Light/dark theme toggle
- Responsive layout across desktop and mobile
- Skills overview across programming, web development, databases/tools, and systems/AI
- Featured projects grid linking to live sites and repositories
- Contact section with direct email, phone, GitHub, and LinkedIn links

## Tech Stack

This site is built with plain **HTML, CSS, and JavaScript** — no frameworks, no build step. All styling is self-contained within `index.html`.

## Running Locally

Since this is a static site with no dependencies, just clone and open it:

```bash
git clone https://github.com/FxhsZyan/FxhsZyan.github.io.git
cd FxhsZyan.github.io
```

Then open `index.html` in your browser.
